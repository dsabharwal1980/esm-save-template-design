Design rules — field-level constraints, validation severity, and data model notes.

Field specifications

Field Rule Behaviour
Template Name Required Blocking. Field cannot be empty. Save button disabled until a value is entered.
Validation — special chars Blocking. Only a–z A–Z 0–9 space - _ allowed. Show red error inline. Save button disabled.
Validation — max length Blocking. Max 80 chars. Character counter shown; turns amber at 68+, red when exceeded. Save button disabled.
Validation — duplicate name Blocking. Checked live as user types, case-insensitive, against existing SalesConfigTemplate__c records. Show red error: "A template named '[name]' already exists. Please choose a unique name." Save disabled. When editing an existing template, the check must exclude the current record (i.e. re-saving with the same name is allowed).
Category Data model Text field on SalesConfigTemplate__c. Not a separate object — value is a plain string stored directly on the template record. Combobox options are the distinct Category values queried from existing SalesConfigTemplate__c records (i.e. SELECT Category__c FROM SalesConfigTemplate__c GROUP BY Category__c). No separate Category object exists.
UI pattern Combobox — user types to filter existing categories from other templates, or types a new name. Existing options show Existing badge. New values show New badge on the chip after selection.
Validation — special chars Blocking. Only a–z A–Z 0–9 space - _ allowed. Show red error inline. Save button disabled.
Validation — max length Blocking. Max 255 chars. Character counter shown; turns red when exceeded. Save button disabled.
Tags Data model Tags are stored in SalesConfigTemplateTag__c. The link to a template is a separate junction object SalesConfigTemplateTagLink__c.
UI pattern Multi-select combobox. User types to search existing SalesConfigTemplateTag__c records. Selecting an existing tag creates a SalesConfigTemplateTagLink__c record on save. Creating a new tag inserts a new SalesConfigTemplateTag__c + link on save.
Validation — special chars Blocking. Same character allowlist as Category. Inline error message. Save disabled until corrected or input cleared.
Validation — max length Blocking. Max 80 chars. Character counter shown; turns amber at 65+, red when exceeded. Prevents adding the tag.
Duplicate tag warning Non-blocking. If typed name matches an existing SalesConfigTemplateTag__c record, show amber inline warning: "A tag with this name already exists — selecting it links to the existing record." User can still select it; no duplicate record is created.
Selecting existing category Info — non-blocking When the user selects an existing category from the dropdown (or types a name that exactly matches one), show a blue info message: "This category already exists — selecting it groups this template with others in the same category." This is the expected behaviour — no warning needed, no duplicate is created. The same string is stored on the new template record.
Creating a new category When the user types a name not present in any existing template and chooses "+ Create '[name]'", the string is stored as-is on the new template. It will appear as an option in the combobox for future templates automatically.
Save button Enable / disable Disabled when any blocking validation error is present (special chars, length exceeded, required Template Name empty). Non-blocking warnings (duplicate category/tag) do not disable save.
